# Controls

Every action is in the menu bar, in the **command menu** (**⌘K** on a Mac, **Ctrl+K** on Windows and Linux) and in the **Keyboard Shortcuts** window (**⌘/** or **Ctrl+/**, or **Help → Keyboard Shortcuts**). That window is built from the same list as the menus, so it is always up to date. Its **Press a Shortcut…** button tells you what any key does: press keys and it names the command each one runs, or says there is none. **Esc** or **Stop** ends it.

Single-letter shortcuts (**P**, **N**, **F**) work when no text field has the keyboard. In a text field they type the letter.

In a browser tab, **⌘N** (**Ctrl+N**) belongs to the browser, which opens a new window. Use the command menu there for New Ledger.

## Ledgers

| Action                                        | macOS                   | Windows / Linux         |
| --------------------------------------------- | ----------------------- | ----------------------- |
| New ledger                                    | **⌘N**                  | **Ctrl+N**              |
| Open another ledger                           | click the ledger's name | click the ledger's name |
| Keep ledgers in another folder                | **⌘O**                  | **Ctrl+O**              |
| Rename, delete or export the ledger, or trash | **File** menu or **⌘K** | **File** menu or **⌘K** |

## People

| Action                                 | macOS                  | Windows / Linux        |
| -------------------------------------- | ---------------------- | ---------------------- |
| Add a person                           | **P**, type, **↩**     | **P**, type, **Enter** |
| Show a person's transactions           | click the person       | click the person       |
| Rename or remove a person              | right-click the person | right-click the person |
| Open a person's menu from the keyboard | **⇧F10**               | **Shift+F10**          |

## Transactions

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| New transaction: go to the Amount field | **N** | **N** |
| Add the transaction you typed | **↩** | **Enter** |
| Open the From or To list | **Space** or **↓** | **Space** or **Down** |
| Move through an open From or To list | **⇥** / **⇧⇥** or **↓** / **↑** | **Tab** / **Shift+Tab** or **Down** / **Up** |
| Pick the name, or close the list without picking | **↩** / **Esc** | **Enter** / **Esc** |
| Jump to a name in From or To | its first letter | its first letter |
| Previous / next transaction in the list | **↑** / **↓** | **Up** / **Down** |
| First / last transaction | **↖** / **↘** | **Home** / **End** |
| Edit the chosen transaction | **↩** or double-click | **Enter** or double-click |
| Delete the chosen transaction | **⌦** or **⌫** | **Delete** or **Backspace** |
| Swap direction, edit or delete | right-click the transaction | right-click the transaction |
| Undo / redo a change to the ledger | **⌘Z** / **⇧⌘Z** | **Ctrl+Z** / **Ctrl+Shift+Z** |

## Diagram

| Action | macOS | Windows / Linux |

| Show the transactions behind an arrow | click the arrow or its Totals row | click the arrow or its Totals row |
| Show every transaction again | **⎋** | **Esc** |
