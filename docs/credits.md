# Credits

IOUinator's own code and its app icon are covered by its [MIT license](../LICENSE). It is built on these projects:

- [Preact](https://preactjs.com) and [Preact Signals](https://github.com/preactjs/signals): the user interface. MIT license.
- [Mermaid](https://mermaid.js.org): draws the diagram of who owes whom. It is bundled with the app and loaded the first time the diagram is shown. MIT license.
- [Electron](https://www.electronjs.org): the desktop app. MIT license.
- [Lucide](https://lucide.dev): the shapes of the icons in the top bar, status bar and dialogs. ISC license.

The build and test tools (Vite, TypeScript, Vitest, Playwright, ESLint, Prettier, electron-builder) are listed in the `package.json` files and aren't part of the app.
